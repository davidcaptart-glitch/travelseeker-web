# TravelSeeker · web

Landing de [TravelSeeker](https://travelseeker.vercel.app): alertas de vuelos y alojamiento en tus días libres.

Publicada con GitHub Pages en https://davidcaptart-glitch.github.io/travelseeker-web/

Es una sola página estática (`index.html`). El formulario de contacto usa FormSubmit: el destino está en la constante `FORM_TARGET`.
